# VRChat アバター使用アセット画像メーカー

VRChatの改変済みアバターに使用したアセットを紹介する画像を作成できるWebアプリ（名称未定）。

## 技術スタックの選定理由

### Nuxt 3

- 選定理由：
  - Webアプリとして一般公開するため、SEO・OGPが必要だった
  - サムネイル取得時にCORP由来の問題が発生することを防ぐために、サーバーサイドのAPIも実装する必要があった。
- 比較した候補：
  - Vue.js：規模的にNuxt3を導入する必要は無いと想定していたが、上記選定理由から多少のオーバースペックを許容してでも享受できるメリットが大きいと判断した
  - Next.js / React：今回の要件については、サーバー依存の情報取得などが少なく、Server ComponentなどNuxtと比較して多少複雑な設計を採用するよりは、実装コスト等を鑑みてNuxt3を採用することにした

### Vite

- 選定理由：開発スピード向上のため
- 比較した候補：特になし
